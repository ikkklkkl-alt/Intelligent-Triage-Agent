# IMCS 智能医疗预约诊疗系统

基于 FastAPI + PostgreSQL/pgvector + Celery + Redis + DeepSeek + Vue 3 的智能医疗预约诊疗系统。

## 核心亮点

| 能力 | 实现 |
|---|---|
| 统一 LLM 服务层 | Token 日预算(Redis)、调用日志入库、超时重试、DeepSeek→Qwen 多供应商降级链、SSE 流式 |
| 混合检索 RAG | pgvector 余弦检索 + jieba 分词 PG 全文检索 + RRF 融合，检索日志可回放 |
| 智能分诊 Agent | 多轮对话状态机：审核 → RAG 注入 → 流式生成 → 结构化结论 → 规则引擎兜底 |
| 异步任务 | Celery + Redis：知识库分块向量化、检验报告 AI 解读；LLM 失败自动降级为规则摘要 |
| 内容审核 | 输入敏感词/提示注入拦截，心理危机语句返回求助热线 |
| AI 运行监控 | llm_call_logs / rag_query_logs 双日志表，管理端看板展示调用量、Token、时延、降级率 |

## 完整就诊流程

```
患者                           医院系统                        医生/工作人员
 │                              │                              │
 ├─ 1. 智能分诊 ──────────────►│ AI 推荐科室                   │
 │   (描述症状，AI 推荐科室)     │ (RAG + LLM 多轮对话)          │
 │                              │                              │
 ├─ 2. 预约挂号 ──────────────►│ 创建排班预约                   │
 │   (选医生、选时段)            │ (行锁防超卖)                   │
 │                              │                              │
 ├─ 3. 到院就诊 ──────────────►│ 医生工作列表显示               ├─ 4. 接诊
 │                              │ 当日预约患者                   │   (查看病历、开处方/检验)
 │                              │                              │
 ├─ 5. 缴费 ─────────────────►│ 生成缴费单                     ├─ 收费员确认收费
 │   (到收费窗口)               │ (处方费 + 检验费)              │
 │                              │                              │
 │                              │                              ├─ 6. 检验师录入结果
 │                              │                              │   (提交检验报告)
 │                              │                              │
 │                              │ Celery 异步 AI 解读报告        │
 │                              │ (pgvector RAG 知识库辅助)      │
 │                              │                              │
 ├─ 7. 查看报告 ──────────────►│ 报告含 AI 摘要                 │
 │   (AI 解读的检验报告)         │ + 异常指标 + 建议              │
 │                              │                              │
 │                              │                              ├─ 8. 药师确认发药
 │                              │                              │
 └─ 9. 完成就诊                 │ 病历归档                      └─ 医生关闭病历
```

## 功能详情（按角色）

### 患者端
- **就诊指南**：首页展示完整就诊流程、待缴费提醒、近期预约和报告
- **智能分诊**：多轮对话 AI 分诊助手，支持历史会话查看，自动推荐科室并跳转挂号
- **预约挂号**：按科室筛选医生，查看排班时段，选择预约（今天预约当天可就诊）
- **缴费记录**：分"待缴费/已缴费"标签页，待缴费项置顶高亮，提示到收费窗口缴费
- **我的报告**：展示检验报告列表和 AI 解读状态（解读中/已解读），点击查看详细解读

### 医生端
- **今日待接诊**：显示当日已预约患者列表，一键开始接诊
- **接诊页面**：填写主诉/诊断/诊疗计划，开处方（药品+规格+用法），开检验单，完成接诊

### 检验师
- **检验工单**：显示已缴费的检验单，录入检验结果文本，触发 AI 自动解读

### 收费员
- **待收费列表**：显示所有待缴费项（处方+检验），确认收费后自动更新处方/检验单状态

### 药师
- **待发药列表**：显示已缴费处方，确认发药后记录发药信息

### 管理员
- **AI 监控看板**：LLM 调用量、Token 消耗、响应时延、降级率统计
- **知识库管理**：上传医学知识文档，系统自动分块向量化用于 RAG 检索
- **LLM 日志**：查看每次 AI 调用的详细日志（模型、Token、耗时、状态）
